# art1616

Retro image effects, ASCII art, and PNG/TXT exports. Everything runs in your browser.

**Run locally:** `npm start`, then open http://127.0.0.1:4173.

**Put it on GitHub:**
1. Create a public repository called `art1616`.
2. Unzip `art1616-github.zip`. Upload everything inside it to the repository (keep the folders).
3. Go to Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Your site link will appear under Pages after deployment.

No installation or build needed. Source website files are in `dist/`.
